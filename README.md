# YouToube | ReadMe
Nous avons choisit pour projet de faire une "copie" du site Youtube.
Vous rretrouverez plus bas une liste des fonctionnalités disponibles sur notre site ainsi que des identifiants de comptes.
## Fonctionnalités
### Sur chaque page
Chaque page contient une barre de navigation permettant de revenir à la page d'accueil, d'afficher les vidéos les plus populaires, un bouton permettant d'accéder au profil utilisateur si un utilisateur est connecté ainsi qu'une barre de recherche.
Chaque page contient aussi une barre de navigation verticale permettant de se connecter si aucun utilisateur n'est connecté ou d'accéder aux différents espaces liés à l'utilisateur sinon comme par exemple son profil, ses vidéos, son historique et un bouton pour se déconnecter.

### Accueil
La page d'accueil contient toutes les vidéos enregistrées sur le site. Chaque vidéo affiichée suir cette page contient une miniature, un titre, un auteur et le nombre de vues.

### Tendances
La page Tendances contient ces mêmes vidéos mais triées du plus grand nombre de vues au plus petit.

### Recherche
La page de recherche contient une liste des vidéos dont le titre ou l'auteur correspond à la recherche.

### Vidéo
La page vidéo contient la vidéo qui peut être visionné, ses informations telles que l'auteur, le titre, nombre de vues, description.
On peut poster un commentaire sur la vidéo et voir la liste des commentaires postés sur la vidéo.
On peut voir la liste des autres vidéos disponibles et les visionner.

### Mon compte
Affiche les différentes informations liées au compte, comme le pseudo et mail.
Il y a la possibilité de changer de mot de passe depuis cette page.

### Mes vidéos
Affiche la liste des vidéos postés par l'utilisateur connecté et permet de poster une nouvelle vidéo directement depuis cette page. On peut aussi poster une vidéo depuis la page **Upload**.

### Upload
On peut poster une nouvelle vidéo depuis cette page en renseignant un titre, une description et en téléversant un fichier de type vidéo.

### Historique
Affiche la liste des vidéos triées dans l'ordre de la vidéo la plus récemment vue à celle la moins récente.

### Se connecter
Dans certaines situations, si l'utilisateur fait une action qui necessite d'être connecté et qu'il ne l'est pas, il sera redirigé vers la page de connexion. Une fois connecté il sera redirigé vers la page où il était précédemment.
Sur la page de connexion on peut accéder à la page de création de compte.

### Création de compte
Dans cette page on peut renseigner un pseudo, mail et mot de passe. Si l'adresse mail est déja utilisée, l'utilisateur se verra refuser la création du compte.
